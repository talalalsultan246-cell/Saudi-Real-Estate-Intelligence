# Data provenance and evidence

## Primary data origin

**CivilLizard. Saudi Real Estate Data (GitHub repository).**  
https://github.com/civillizard/Saudi-Real-Estate-Data

The academic submission used a **consolidated sales file associated with this public repository**. Its report states 1,439,706 unique transaction references covering 2020-01-01 through 2026-03-31. The repository source is not a guarantee that the team's consolidated snapshot is identical to its current latest revision.
